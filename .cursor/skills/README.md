# Skills

В этом каталоге размещаются специализированные знания и повторяемые
рабочие процессы для AI-агентов BotHunter.

Skill добавляется только тогда, когда отдельный загружаемый контекст
даёт практическую пользу и не дублирует Rules, task specifications
или общую документацию проекта.

Перед добавлением стороннего Skill необходимо проверить его содержимое
и требования безопасности.
