# Отчёты об одобренной работе

В этом каталоге хранятся постоянные отчёты о значимых этапах
и задачах, выполненных AI-агентами.

Отчёт дополняет Git-историю, BDD, архитектурную документацию и ADR,
но не заменяет их.

## Когда создавать отчёт

Агент создаёт отчёт только если:

1. работа завершена;
2. обязательные проверки успешно пройдены;
3. предварительная сводка представлена в чате;
4. пользователь явно одобрил результат.

Один отчёт соответствует одному одобренному значимому этапу
или одной значимой задаче.

Не создавать отчёты для незавершённых, отклонённых или не прошедших
проверки изменений, промежуточных попыток и консультаций без изменений
проекта.

## Именование

Использовать формат:

```text
YYYY-MM-DD-<task-slug>.md
```

Например:

```text
2026-08-19-agent-work-reporting.md
```

Если в один день создаются отчёты с одинаковым `task-slug`,
добавить последовательный числовой суффикс.

## Содержание

Использовать `TEMPLATE.md`. Фиксировать итоговое одобренное состояние:

- цель и область работы;
- роль выполнившего агента;
- выполненные изменения;
- изменённые файлы;
- проверки и их результаты;
- архитектурное влияние и связанные ADR;
- проблемы, решения и известные ограничения;
- следующий согласованный или предлагаемый шаг;
- факт одобрения результата пользователем.

Не включать внутренние рассуждения агента, историю вызовов инструментов,
необработанные логи, секреты и чувствительные данные.

Одобрение результата не означает разрешение перейти к следующему этапу.
Переход требует отдельного явного подтверждения пользователя.
