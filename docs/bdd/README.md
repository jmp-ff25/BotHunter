# BDD-сценарии

В этом каталоге находятся исполняемые спецификации поведения BotHunter.

Сценарии создаются на соответствующем BDD-этапе процесса разработки
и хранятся в файлах `*.feature`.

Требования к сценариям:

- синтаксис Gherkin;
- английский язык;
- описание наблюдаемого поведения и бизнес-результата;
- независимость от деталей реализации;
- исполнение через pytest-bdd.

Не включать в сценарии CSS-селекторы, XPath, детали Playwright,
имена внутренних классов, методов и структуру Page Objects.

До утверждения поведения конкретной функциональности не создавать
файлы-заглушки.

## Русский перевод сценариев

Исполняемые сценарии остаются на английском. Для чтения на русском
к каждому `*.feature` создаётся парный файл:

```text
docs/bdd/<name>.feature
docs/bdd/<name>.feature.ru.md
```

Файл `*.feature.ru.md`:

- не исполняется pytest-bdd;
- полностью зеркалит парный `.feature` на русском Gherkin
  (`# language: ru`, `Функция`, `Предыстория`, `Сценарий`, `Дано`, `Когда`, `Тогда`, `И`);
- сохраняет ту же структуру, число сценариев и шагов, что и `.feature`;
- обновляется вместе с парным `.feature`;
- при расхождении приоритет у `.feature` на английском.
