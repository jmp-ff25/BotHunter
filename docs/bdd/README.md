# BDD-сценарии

В этом каталоге находятся исполняемые спецификации поведения BotHunter.

Сценарии создаются на соответствующем BDD-этапе процесса разработки
и хранятся в файлах `*.feature`.

Требования к сценариям:

- синтаксис Gherkin;
- английский язык;
- описание наблюдаемого поведения и бизнес-результата;
- независимость от деталей реализации;
- исполнение через pytest-bdd.

Не включать в сценарии CSS-селекторы, XPath, детали Playwright,
имена внутренних классов, методов и структуру Page Objects.

До утверждения поведения конкретной функциональности не создавать
файлы-заглушки.
