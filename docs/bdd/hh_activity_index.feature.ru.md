# Поддержка индекса активности HH

Парный файл: [`hh_activity_index.feature`](hh_activity_index.feature)

> Неисполняемый перевод для чтения. Источник истины — `.feature` на английском.

**Отдельный модуль:** периодически (каждые N часов) повышает индекс активности
резюме на HH. Может запускаться **после откликов** или **параллельно** с ними,
затем **засыпает** до следующего цикла.

**Не делает:** не отправляет **свои** сообщения работодателям.
**Делает в чатах:** только нажимает **предложенные кнопки HH** (график, локация и т.д.).

## Feature

**Как** владелец BotHunter  
**Я хочу** отдельный модуль поддержки индекса активности  
**Чтобы** резюме оставалось заметным на HH без переписки от имени бота

---

## Расписание модуля

### Configure activity index maintenance interval — Интервал (каждые N часов)

- Владелец задаёт интервал, например каждые 4 часа.

### Activity index module runs on schedule — Запуск по расписанию

- В назначенное время модуль начинает цикл обслуживания.

### Activity index module sleeps until the next scheduled run — Ожидание

- После цикла модуль засыпает до следующего запуска; видно время следующего run.

### Run after applications complete — После пакета откликов

- Модуль может стартовать после завершения batch откликов.

### Run in parallel with applications — Параллельно с откликами

- Модуль может работать параллельно, отклики продолжаются по политике.

---

## Действия для индекса активности

| Сценарий | Смысл |
|---|---|
| View vacancies | Просмотр/прокрутка вакансий на HH |
| Raise resume in search | Кнопка «поднять резюме в поиске» |
| Completed-action phrasing | Формулировки «сделал», не «делал» в резюме на HH |
| Achievement statements | Конкретные достижения («ускорил на 90%…») |
| Click HH suggested chat buttons | Только кнопки HH в чате, без своего текста |
| Never sends custom employer messages | Никаких собственных сообщений работодателю |

---

## Контроль и видимость

- История циклов и выполненных действий.
- **Не запускается на паузе** автоматизации.
- Владелец может **отключить** модуль.

---

## Вне этой области

- Отклики как бизнес-процесс → Application submission
- Переписка с работодателем вручную → не автоматизируется (см. profile_policies)
