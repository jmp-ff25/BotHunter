# Поиск вакансий

Парный файл: [`vacancy_discovery.feature`](vacancy_discovery.feature)

> Неисполняемый перевод для чтения. Источник истины — `.feature` на английском.
> При изменении сценариев обновляйте этот файл вместе с ними.

Использует предпочтения поиска из области 1 (`profile_policies_and_limits.feature`)
и требует запущенной автоматизации (`automation_control.feature`).

## Feature

**Как** владелец BotHunter  
**Я хочу**, чтобы BotHunter находил подходящие вакансии из подключённых источников  
**Чтобы** дальше по workflow шли только релевантные новые вакансии

**Background:** BotHunter локально, предпочтения поиска настроены, автоматизация запущена.

---

## Принятие вакансий

### Discover a vacancy that matches search preferences — Вакансия соответствует фильтрам

- **Когда:** BotHunter обнаруживает вакансию, подходящую под предпочтения поиска
- **Тогда:** владелец видит, что вакансия доступна для дальнейшей обработки
- **И:** видит причину принятия

### Do not rediscover an already accepted vacancy — Без повторного обнаружения принятой вакансии

- **Дано:** вакансия уже обнаружена и принята для дальнейшей обработки
- **Когда:** BotHunter снова находит ту же вакансию
- **Тогда:** нет дубликата в списке
- **И:** вакансия не считается новой

---

## Исключение по предпочтениям поиска

### Exclude vacancy with an exclusion word in the title — Слово-исключение в заголовке

- **Дано:** настроены слова-исключения для заголовков
- **Когда:** в заголовке вакансии есть такое слово
- **Тогда:** вакансия исключена из дальнейшей обработки
- **И:** в причине указан заголовок

### Exclude vacancy with an exclusion word in the description — Слово-исключение в описании

- **Дано:** настроены слова-исключения для описаний
- **Когда:** в описании есть такое слово
- **Тогда:** вакансия исключена
- **И:** в причине указано описание

### Exclude vacancy missing a required word in the title — Нет обязательного слова в заголовке

- **Дано:** настроены обязательные слова для заголовков
- **Когда:** в заголовке нет обязательного слова
- **Тогда:** вакансия исключена
- **И:** в причине указан заголовок

### Exclude vacancy missing a required word in the description — Нет обязательного слова в описании

- **Дано:** настроены обязательные слова для описаний
- **Когда:** в описании нет обязательного слова
- **Тогда:** вакансия исключена
- **И:** в причине указано описание

### Exclude vacancy outside the desired compensation range — Вилка вне диапазона

- **Дано:** настроена желаемая вилка компенсации
- **Когда:** компенсация вакансии вне диапазона
- **Тогда:** вакансия исключена
- **И:** в причине указана вилка

### Do not reprocess an already excluded vacancy — Без повторной обработки исключённой

- **Дано:** вакансия уже обнаружена и исключена
- **Когда:** BotHunter снова находит ту же вакансию
- **Тогда:** нет дубликата
- **И:** вакансия остаётся исключённой

## Обзор результатов поиска

### Review discovered vacancies available for further processing — Список принятых

- **Дано:** есть вакансии, доступные для дальнейшей обработки
- **Когда:** владелец просматривает обнаруженные вакансии
- **Тогда:** видит, какие доступны для дальнейшей обработки

### Review vacancies excluded by search preferences — Список исключённых

- **Дано:** есть вакансии, исключённые фильтрами
- **Когда:** владелец просматривает исключённые вакансии
- **Тогда:** видит какие исключены и почему каждая

---

## Состояние автоматизации

### Do not discover vacancies while automation is paused — Нет поиска на паузе

- **Дано:** автоматизация на паузе
- **Когда:** на источнике появляется новая вакансия
- **Тогда:** BotHunter её не обнаруживает

### Do not discover vacancies while automation is not running — Нет поиска без запуска

- **Дано:** автоматизация не запущена
- **Когда:** на источнике появляется новая вакансия
- **Тогда:** BotHunter её не обнаруживает
