# language: ru
Функция: Поиск вакансий
  Как владелец BotHunter
  Я хочу, чтобы BotHunter находил подходящие вакансии из подключённых источников
  Чтобы дальше по workflow проходили только релевантные новые вакансии

  Предыстория:
    Дано BotHunter запущен локально для владельца
    И владелец настроил предпочтения поиска
    И автоматизация запущена

  # --- Принятие вакансий ---

  Сценарий: Обнаружение вакансии, соответствующей предпочтениям поиска
    Когда BotHunter обнаруживает вакансию, соответствующую предпочтениям поиска
    Тогда владелец видит, что вакансия доступна для дальнейшей обработки
    И владелец видит, почему вакансия была принята

  Сценарий: Повторное обнаружение уже принятой вакансии не выполняется
    Дано вакансия уже была обнаружена и принята для дальнейшей обработки
    Когда BotHunter снова обнаруживает ту же вакансию
    Тогда владелец не видит дублирующей записи вакансии
    И вакансия не считается новым обнаружением

  # --- Исключение по предпочтениям поиска ---

  Сценарий: Исключение вакансии со словом-исключением в заголовке
    Дано владелец настроил слова-исключения для заголовков вакансий
    Когда BotHunter обнаруживает вакансию, в заголовке которой есть слово-исключение
    Тогда владелец видит, что вакансия исключена из дальнейшей обработки
    И владелец видит, что причина исключения ссылается на заголовок

  Сценарий: Исключение вакансии со словом-исключением в описании
    Дано владелец настроил слова-исключения для описаний вакансий
    Когда BotHunter обнаруживает вакансию, в описании которой есть слово-исключение
    Тогда владелец видит, что вакансия исключена из дальнейшей обработки
    И владелец видит, что причина исключения ссылается на описание

  Сценарий: Исключение вакансии без обязательного слова в заголовке
    Дано владелец настроил обязательные слова для заголовков вакансий
    Когда BotHunter обнаруживает вакансию, в заголовке которой нет обязательного слова
    Тогда владелец видит, что вакансия исключена из дальнейшей обработки
    И владелец видит, что причина исключения ссылается на заголовок

  Сценарий: Исключение вакансии без обязательного слова в описании
    Дано владелец настроил обязательные слова для описаний вакансий
    Когда BotHunter обнаруживает вакансию, в описании которой нет обязательного слова
    Тогда владелец видит, что вакансия исключена из дальнейшей обработки
    И владелец видит, что причина исключения ссылается на описание

  Сценарий: Исключение вакансии вне желаемой вилки компенсации
    Дано владелец настроил желаемую вилку компенсации
    Когда BotHunter обнаруживает вакансию с компенсацией вне желаемой вилки
    Тогда владелец видит, что вакансия исключена из дальнейшей обработки
    И владелец видит, что причина исключения ссылается на вилку компенсации

  Сценарий: Повторная обработка уже исключённой вакансии не выполняется
    Дано вакансия уже была обнаружена и исключена из дальнейшей обработки
    Когда BotHunter снова обнаруживает ту же вакансию
    Тогда владелец не видит дублирующей записи вакансии
    И вакансия остаётся исключённой из дальнейшей обработки

  # --- Обзор результатов поиска ---

  Сценарий: Просмотр обнаруженных вакансий, доступных для дальнейшей обработки
    Дано BotHunter обнаружил вакансии, доступные для дальнейшей обработки
    Когда владелец просматривает обнаруженные вакансии
    Тогда владелец видит, какие вакансии доступны для дальнейшей обработки

  Сценарий: Просмотр вакансий, исключённых по предпочтениям поиска
    Дано BotHunter обнаружил вакансии, исключённые по предпочтениям поиска
    Когда владелец просматривает исключённые вакансии
    Тогда владелец видит, какие вакансии были исключены
    И владелец видит, почему каждая вакансия была исключена

  # --- Состояние автоматизации ---

  Сценарий: Поиск вакансий не выполняется на паузе автоматизации
    Дано автоматизация на паузе
    Когда на подключённом источнике вакансий появляется вакансия
    Тогда BotHunter не обнаруживает вакансию

  Сценарий: Поиск вакансий не выполняется при незапущенной автоматизации
    Дано автоматизация не запущена
    Когда на подключённом источнике вакансий появляется вакансия
    Тогда BotHunter не обнаруживает вакансию
