# Резюме, предпочтения поиска, политики и лимиты

Парный файл: [`profile_policies_and_limits.feature`](profile_policies_and_limits.feature)

> Неисполняемый перевод для чтения. Источник истины — `.feature` на английском.
> При изменении сценариев обновляйте этот файл вместе с ними.

Модель: **резюме загружается один раз** и используется системой (в т.ч. через RAG)
для оценки вакансий и подготовки откликов. Вне резюме владелец задаёт только
**вилку компенсации**, **слова-исключения** и **обязательные слова** при чтении
заголовка и описания вакансии. Остальное — из CV и политики автоматизации.

## Feature

**Как** владелец BotHunter  
**Я хочу** зарегистрировать резюме, задать предпочтения поиска вне резюме и настроить политики и лимиты автоматизации  
**Чтобы** автоматический поиск использовал моё CV и соблюдал мои границы

**Background:** BotHunter запущен локально для владельца.

---

## Резюме

### View automation readiness before initial setup — Проверка готовности до первой настройки

- **Дано:** резюме не зарегистрировано, предпочтения поиска не настроены
- **Когда:** владелец открывает настройки автоматизации
- **Тогда:** владелец видит, что автоматизация не готова
- **И:** владелец видит, какие обязательные пункты настройки ещё не выполнены

### Register owner resume — Регистрация резюме

- **Дано:** у владельца есть документ резюме
- **Когда:** владелец регистрирует резюме в BotHunter
- **Тогда:** владелец видит, что резюме зарегистрировано
- **И:** владелец видит, какой документ резюме активен

### Replace registered owner resume — Замена зарегистрированного резюме

- **Дано:** у владельца уже есть зарегистрированное резюме
- **Когда:** владелец регистрирует новый документ резюме
- **Тогда:** владелец видит, что активен новый документ резюме

---

## Предпочтения поиска вне резюме

### Configure vacancy search preferences — Настройка предпочтений поиска

- **Когда:** владелец задаёт желаемую вилку компенсации
- **И:** задаёт слова-исключения для заголовков и описаний вакансий
- **И:** задаёт обязательные слова для заголовков и описаний вакансий
- **И:** сохраняет предпочтения поиска
- **Тогда:** владелец видит активную вилку компенсации
- **И:** видит активные слова-исключения
- **И:** видит активные обязательные слова

### Update vacancy search preferences — Обновление предпочтений поиска

- **Дано:** предпочтения поиска сохранены
- **Когда:** владелец обновляет вилку, слова-исключения и обязательные слова
- **И:** сохраняет предпочтения поиска
- **Тогда:** владелец видит обновлённую вилку, исключения и обязательные слова

## Политика полной автоматизации

### Full automation remains disabled until explicitly enabled — Полная автоматизация выключена до явного включения

- **Дано:** владелец не включал полную автоматизацию
- **Когда:** владелец просматривает политику автоматизации
- **Тогда:** полная автоматизация отображается как выключенная
- **И:** автоматические внешние действия не разрешены

### Enable full automation with complete configuration — Включение при полной конфигурации

- **Дано:** зарегистрировано резюме, настроены предпочтения поиска, типы действий, дневные лимиты, правила подготовки откликов, ответов работодателям и случаи вмешательства
- **Когда:** владелец явно включает полную автоматизацию
- **Тогда:** полная автоматизация включена
- **И:** владелец видит разрешённые автоматические действия

### Cannot enable full automation without a registered resume — Нельзя включить без резюме

- **Дано:** резюме не зарегистрировано, остальная конфигурация выполнена
- **Когда:** владелец пытается включить полную автоматизацию
- **Тогда:** полная автоматизация остаётся выключенной
- **И:** владелец получает сообщение, что требуется зарегистрированное резюме

### Cannot enable full automation without search preferences — Нельзя включить без предпочтений поиска

- **Дано:** резюме зарегистрировано, предпочтения поиска не настроены, остальная конфигурация выполнена
- **Когда:** владелец пытается включить полную автоматизацию
- **Тогда:** полная автоматизация остаётся выключенной
- **И:** владелец получает сообщение, что требуются предпочтения поиска

### Disable full automation — Отключение полной автоматизации

- **Дано:** полная автоматизация включена
- **Когда:** владелец отключает полную автоматизацию
- **Тогда:** полная автоматизация выключена, внешние действия не разрешены

## Разрешённые типы автоматических действий

### Configure allowed automatic action types — Настройка разрешённых типов действий

- **Когда:** владелец разрешает автоматические отклики и запрещает автоматические сообщения работодателям, затем сохраняет политику
- **Тогда:** владелец видит соответствующие разрешения

### Change allowed automatic action types — Изменение разрешённых типов действий

- **Дано:** отклики разрешены, сообщения запрещены
- **Когда:** владелец меняет разрешения на противоположные и сохраняет политику
- **Тогда:** владелец видит обновлённые разрешения

---

## Лимиты действий

### Configure daily application limit — Дневной лимит откликов

- **Когда:** владелец устанавливает лимит 10 откликов в день и сохраняет политику
- **Тогда:** владелец видит дневной лимит откликов: 10

### Configure daily outgoing message limit — Дневной лимит исходящих сообщений

- **Когда:** владелец устанавливает лимит 5 исходящих сообщений в день и сохраняет политику
- **Тогда:** владелец видит дневной лимит сообщений: 5

### Update daily action limits — Обновление дневных лимитов

- **Дано:** лимит откликов: 10
- **Когда:** владелец меняет лимит на 3 и сохраняет политику
- **Тогда:** владелец видит дневной лимит откликов: 3

---

## Правила подготовки и вмешательства

### Configure application preparation rules — Правила подготовки откликов

- **Когда:** владелец задаёт правила подготовки откликов и сохраняет политику
- **Тогда:** владелец может просмотреть активные правила

### Configure employer message response rules — Правила ответов работодателям

- **Когда:** владелец задаёт правила ответов на сообщения работодателей и сохраняет политику
- **Тогда:** владелец может просмотреть активные правила

### Configure situations that require owner intervention — Случаи, требующие вмешательства

- **Когда:** владелец указывает, что неясные запросы работодателя требуют его вмешательства, и сохраняет политику
- **Тогда:** владелец видит это правило в конфигурации

---

## Обзор политики и сохранение

### Review active automation policy summary — Сводка активной политики

- **Дано:** полная конфигурация выполнена, автоматизация включена
- **Когда:** владелец просматривает сводку политики
- **Тогда:** видит статус автоматизации, активное резюме, предпочтения поиска, разрешённые действия, лимиты и ключевые правила

### Saved resume, search preferences, and policies remain available after restart — Сохранение после перезапуска

- **Дано:** зарегистрировано резюме, сохранены предпочтения поиска и политика
- **Когда:** BotHunter перезапускается
- **Тогда:** владелец видит ту же конфигурацию резюме, предпочтений и политики
