# Резюме, предпочтения поиска, политики и лимиты

Парный файл: [`profile_policies_and_limits.feature`](profile_policies_and_limits.feature)

> Неисполняемый перевод для чтения. Источник истины — `.feature` на английском.
> При изменении сценариев обновляйте этот файл вместе с ними.

Модель: **резюме загружается один раз**; вне CV — **вилка**, **слова-исключения**,
**обязательные слова**. **Переписка с работодателями только вручную.**
Уведомления — **статистика откликов** (день, отказы, месяц).

## Feature

**Как** владелец BotHunter  
**Я хочу** зарегистрировать резюме, задать предпочтения поиска вне резюме и настроить политики и лимиты  
**Чтобы** автоматический поиск использовал моё CV и соблюдал мои границы

---

## Резюме

### View automation readiness before initial setup — Готовность до первой настройки

- **Дано:** резюме не зарегистрировано, предпочтения поиска не настроены
- **Когда:** владелец открывает настройки автоматизации
- **Тогда:** автоматизация не готова, видно что ещё требуется

### Register owner resume — Регистрация резюме

- **Когда:** владелец регистрирует документ резюме
- **Тогда:** видно активное зарегистрированное резюме

### Replace registered owner resume — Замена резюме

- **Когда:** владелец регистрирует новый документ
- **Тогда:** активен новый документ

---

## Предпочтения поиска вне резюме

### Configure / Update vacancy search preferences — Настройка и обновление

- Вилка компенсации, слова-исключения и обязательные слова для заголовка и описания вакансии.

---

## Политика полной автоматизации

- Включение только при: резюме, предпочтениях поиска, дневном лимите откликов, правилах подготовки откликов, случаях вмешательства.
- Автоматизируются **только отклики**, не переписка.
- Блокировка включения без резюме или без предпочтений поиска.

---

## Лимиты откликов

- Настройка и обновление **дневного лимита откликов** (без лимитов сообщений).

---

## Правила и вмешательство

- Правила подготовки откликов.
- Неясные ситуации при отклике → вмешательство владельца.
- **Employer communication remains manual** — переписка с работодателями только у владельца, система не автоматизирует общение.

---

## Уведомления о статистике откликов

### Receive daily application count notification — Отклики за день

- Владелец получает число откликов за текущий день.

### Receive notification when rejections are present — Наличие отказов

- Владелец узнаёт, что есть отказы.

### View total application count for the recent month — Итого за месяц

- Владелец видит общее число откликов за ближайший месяц.

---

## Обзор и сохранение

- Сводка политики включает явное указание: **общение с работодателями не автоматизируется**.
- Конфигурация сохраняется после перезапуска.
