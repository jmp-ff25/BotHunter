# Управление автоматизацией

Парный файл: [`automation_control.feature`](automation_control.feature)

> Неисполняемый перевод для чтения. Источник истины — `.feature` на английском.
> При изменении сценариев обновляйте этот файл вместе с ними.

Зависит от области 1: запуск возможен только после полной настройки
и явного включения полной автоматизации (`profile_policies_and_limits.feature`).

## Feature

**Как** владелец BotHunter  
**Я хочу** запускать, приостанавливать и возобновлять автоматизацию поиска работы  
**Чтобы** включать её когда всё готово и немедленно останавливать в любой момент

**Background:** BotHunter запущен локально для владельца.

---

## Статус автоматизации

### View automation status when idle and ready — Статус: готова к запуску

- **Дано:** настройка завершена, полная автоматизация включена, автоматизация не запущена
- **Когда:** владелец смотрит статус
- **Тогда:** видит, что автоматизация простаивает и готова к запуску

### View automation status while running — Статус: выполняется

- **Дано:** автоматизация запущена
- **Когда:** владелец смотрит статус
- **Тогда:** видит, что автоматизация выполняется

### View automation status while paused — Статус: на паузе

- **Дано:** автоматизация на паузе
- **Когда:** владелец смотрит статус
- **Тогда:** видит, что автоматизация на паузе

### View automation status when the worker is unavailable — Worker недоступен

- **Дано:** automation worker недоступен
- **Когда:** владелец смотрит статус
- **Тогда:** видит, что автоматизация недоступна
- **И:** автоматические внешние действия не выполняются

---

## Запуск автоматизации

### Start automation when ready — Запуск при готовности

- **Дано:** настройка завершена, полная автоматизация включена, автоматизация не запущена
- **Когда:** владелец запускает автоматизацию
- **Тогда:** видит, что автоматизация выполняется

### Cannot start automation when full automation is disabled — Нельзя запустить без включённой полной автоматизации

- **Дано:** настройка завершена, но полная автоматизация выключена
- **Когда:** владелец пытается запустить
- **Тогда:** автоматизация не стартует
- **И:** сообщение, что нужно сначала включить полную автоматизацию

### Cannot start automation when setup is incomplete — Нельзя запустить при неполной настройке

- **Дано:** настройка не завершена
- **Когда:** владелец пытается запустить
- **Тогда:** автоматизация не стартует
- **И:** сообщение, что автоматизация не готова

### Cannot start automation while paused without resuming — Нельзя «запустить» с паузы без resume

- **Дано:** автоматизация на паузе
- **Когда:** владелец пытается запустить (не resume)
- **Тогда:** остаётся на паузе
- **И:** сообщение, что нужно возобновить (resume), а не запускать заново

---

## Пауза

### Pause running automation — Постановка на паузу

- **Дано:** автоматизация выполняется
- **Когда:** владелец запрашивает паузу
- **Тогда:** видит статус «на паузе»

### No new automatic external actions while paused — Нет новых внешних действий на паузе

- **Дано:** автоматизация на паузе
- **Когда:** иначе было бы выполнено новое автоматическое внешнее действие
- **Тогда:** новое внешнее действие не начинается

### Pause does not cancel an external action already in progress — Пауза не отменяет уже начатое действие

- **Дано:** автоматизация работает, внешнее действие уже выполняется
- **Когда:** владелец запрашивает паузу
- **Тогда:** статус «на паузе»
- **И:** владелец видит, что начатое действие может всё ещё завершиться

### Pause takes effect before the next automatic external action — Пауза до следующего внешнего действия

- **Дано:** автоматизация работает и вот-вот выполнит новое внешнее действие
- **Когда:** владелец запрашивает паузу
- **Тогда:** статус «на паузе», новое внешнее действие не начинается

---

## Возобновление

### Resume paused automation — Возобновление с паузы

- **Дано:** настройка завершена, полная автоматизация включена, автоматизация на паузе
- **Когда:** владелец возобновляет автоматизацию
- **Тогда:** видит, что автоматизация выполняется

### Cannot resume automation when full automation was disabled while paused — Нельзя resume без полной автоматизации

- **Дано:** на паузе, полная автоматизация выключена
- **Когда:** владелец пытается возобновить
- **Тогда:** остаётся на паузе
- **И:** сообщение, что нужно включить полную автоматизацию

---

## Сохранение состояния

### Paused automation remains paused after restart — Пауза сохраняется после перезапуска

- **Дано:** автоматизация на паузе
- **Когда:** BotHunter перезапускается
- **Тогда:** владелец видит, что автоматизация всё ещё на паузе

### Running automation is safely stopped after restart — Безопасное состояние после перезапуска

- **Дано:** автоматизация была запущена
- **Когда:** BotHunter перезапускается
- **Тогда:** владелец видит, что автоматизация не выполняется
- **И:** может понять, нужно ли внимание перед повторным запуском
