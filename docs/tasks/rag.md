# RAG

## Цель

Использовать RAG как реальную функциональную подсистему
BotHunter для анализа вакансий и работы с опытом кандидата.

RAG не должен добавляться только ради демонстрации технологии.

## Основной сценарий

Вакансия
    ↓
Анализ требований
    ↓
Retrieval
    ↓
Knowledge Base кандидата
    ↓
LLM
    ↓
Оценка соответствия

## Дополнительные сценарии

RAG может использоваться для:

- поиска релевантного опыта;
- формирования сопроводительного письма;
- объяснения причины соответствия;
- предоставления контекста AI-компонентам.

## Архитектура

RAG должен быть отделён от основной бизнес-логики
через явный интерфейс.

LangChain использовать как инфраструктурный инструмент,
а не как основу всей бизнес-логики.

LangGraph использовать только при наличии реального
stateful workflow, ветвлений или human-in-the-loop.

RAG разрабатывается по общему процессу
из docs/development-process.md.
