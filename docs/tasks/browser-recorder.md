# Browser Recorder

## Цель

Создать локальный инструмент для исследования веб-интерфейсов
и подготовки технических данных для последующей разработки
автоматизации через Playwright.

Recorder не является AI-системой.

Он собирает факты о взаимодействии пользователя
с браузером и сохраняет их в машиночитаемом формате.

## Pipeline

Playwright Codegen
    ↓
BotHunter Recorder
    ↓
session.json + trace.zip
    ↓
Cursor / Opus
    ↓
BDD + Page Objects

## Recorder должен

- фиксировать действия пользователя;
- сохранять URL и состояние страницы;
- сохранять информацию о локаторах;
- сохранять timestamp;
- сохранять Playwright Trace;
- формировать структурированный session.json.

Trace и JSON не должны дублировать друг друга без необходимости.

session.json должен содержать структурированную информацию
для последующего анализа агентом.

trace.zip используется для детального исследования
через Playwright Trace Viewer.

## AI-анализ

Recorder не должен самостоятельно генерировать BDD
или Page Objects.

После записи данные передаются AI-агенту.

AI должен определить:

- последовательность действий;
- состояния интерфейса;
- возможные ветвления;
- технические локаторы;
- необходимые Page Objects;
- соответствующие BDD-сценарии.

## Разделение ответственности

BDD описывает ЧТО делает система.

Page Object описывает КАК взаимодействовать с интерфейсом.

Playwright выполняет взаимодействие с браузером.

BDD не должен содержать CSS, XPath или детали Playwright.
