# Проектирование реализации

Документы этого каталога описывают способ реализации утверждённого BDD:
модули, границы, порты, зависимости, порядок работ и уровни тестирования.

Документы не дублируют BDD и не заменяют архитектурную модель.
При значимых архитектурных изменениях сначала обновляются
`docs/architecture/` и ADR.

## Файлы

- `implementation-plan.md` — порядок реализации, связь с BDD, матрица тестов.
- `browser-recorder.md` — проектирование Browser Recorder (первая реализация).
- `bothunter-core.md` — проектирование основного приложения BotHunter.
